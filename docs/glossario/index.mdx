# Glossário (A-Z)

Consulte o significado e a finalidade de cada termo técnico e operacional utilizado nos manuais de Garantia e Devolução.

---

<ExpandAllControls />

<DocAccordion title="Autorização do cliente" stepNumber="A" id="term-autorizacao-cliente">

* **Definição**: É o documento que enviamos para o cliente preencher, onde o intuito é receber do cliente a autorização para emitir a NFe de devolução.

</DocAccordion>

<DocAccordion title="Autorização do vendedor" stepNumber="A" id="term-autorizacao-vendedor">

* **Definição**: É o documento de autorização de devolução que o vendedor emite e envia ao cliente logo no início do processo, dando assim o aval de que o vendedor permitiu a devolução.

</DocAccordion>

<DocAccordion title="Espelho" stepNumber="E" id="term-espelho">

* **Definição**: Nota fiscal com dados reais porém ainda não sincronizada com a receita federal (não transmitida). Tem o intuito de revisar a nota antes de enviá-la à receita federal.

</DocAccordion>

<DocAccordion title="NFe" stepNumber="N" id="term-nfe">

* **Definição**: Nota fiscal de devolução.

</DocAccordion>

<DocAccordion title="Peça" stepNumber="P" id="term-peca">

* **Definição**: O produto a ser devolvido.

</DocAccordion>

<DocAccordion title="Requisitos para acolhimento" stepNumber="R" id="term-requisitos-acolhimento">

* **Definição**: É o documento onde o cliente preenche com os dados sobre a compra e sobre o defeito. Usado no início da tratativa para justificar o acionamento da garantia.

</DocAccordion>

<DocAccordion title="Transmitir" stepNumber="T" id="term-transmitir">

* **Definição**: Enviar a nota revisada para a receita federal.

</DocAccordion>
