# Emissão de Guia de Recolhimento ST

Procedimento para identificar a responsabilidade e os passos necessários para a emissão e conferência de guias de **Substituição Tributária (ICMS-ST)** em operações interestaduais.

## Resumo dos Critérios Fiscais

1. **Existência de Convênio / Protocolo ICMS**:
   Define se os estados signatários possuem acordo recíproco de substituição tributária para o segmento de autopeças.
2. **Destaque do Imposto na NF-e**:
   Determina se o valor de ST já foi retido na origem ou se caberá retenção antecipada.
3. **Inscrição de Substituto Tributário**:
   Empresas com IE de substituto no destino realizam recolhimento consolidado mensal; caso contrário, é obrigatório exigir a **GNRE / DAE individual quitada** que acompanha a mercadoria.
