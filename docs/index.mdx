# Guia Mercapeças

Bem-vindo ao **Guia da Mercapeças (Casa do Mercedes)**. 

Esta plataforma centraliza todos os procedimentos operacionais padrão da Mercapeças.

---

## Como Funciona o passo a passo

Para facilitar a leitura e saber exatamente em qual caminho você está, nosso guia utiliza uma estrutura de **passos ramificados**. A lógica funciona como uma árvore de decisões (onde preservamos o histórico do passo pai, passo avô, etc.):

### Exemplo Didático: **Preparar um Lanche**

* **Passo 1:** Pegar o pão. *(Comum)*
* **Passo 2:** Passar manteiga. *(Comum)*
* **Passo 3:** Escolher o tipo de lanche. *(Doce ou Salgado?)*

  Como o **Passo 3** depende de uma escolha, ele inicia uma ramificação:

  * 🍓 **Se escolheu Doce**

    * **Passo 3.1:** Passar geleia. *(Passo Pai: 3 | Passo Atual: .1)*
    * **Passo 3.2:** Fechar o lanche doce. *(Passo Pai: 3 | Passo Atual: .2)*

  * 🧀 **Se escolheu Salgado**

    Como o lanche salgado exige uma nova escolha, inicia-se uma segunda ramificação:

    * 🟡 **Opção: Queijo**

      * **Passo 3.1.1:** Cortar o queijo. *(Passo Avô: 3 | Passo Pai: .1 | Passo Atual: .1)*
      * **Passo 3.1.2:** Derreter o queijo. *(Passo Avô: 3 | Passo Pai: .1 | Passo Atual: .2)*
      * **Passo 3.1.3:** Fechar o pão. *(Passo Avô: 3 | Passo Pai: .1 | Passo Atual: .3)*

    * 🔴 **Opção: Presunto**

      * **Passo 3.2.1:** Dobrar o presunto. *(Passo Avô: 3 | Passo Pai: .2 | Passo Atual: .1)*
      * **Passo 3.2.2:** Colocar no pão. *(Passo Avô: 3 | Passo Pai: .2 | Passo Atual: .2)*


### Como Ler o Código do Passo
* **Prefixos (Passo Pai e Passo Avô):** Mostram de qual decisão você veio (ex: o `3.1` no passo `3.1.2`).
* **Último número:** Mostra qual tarefa exata você deve fazer agora (ex: o `2` no passo `3.1.2`).
