# Processo de Garantia — PJ (Revenda)

Fluxo para acionamento de garantia por clientes **Pessoa Jurídica** enquadrados como **Revendedor**.

---

## Etapas do Processo (Passo 3)

<ExpandAllControls />

<DocAccordion title="3.1.1 [Solicitar Espelho]" stepNumber="3.1.1" id="gar-pj-rev-3-1-1" defaultOpen={true}>

* **Responsável**: Atendimento Geral.
* **Procedimento**: Quando o atendimento geral receber a autorização do vendedor que o cliente encaminhou, então deverá solicitar o **espelho da NFe de garantia**.

</DocAccordion>

<DocAccordion title="3.1.2 [Receber espelho]" stepNumber="3.1.2" id="gar-pj-rev-3-1-2">

* **Responsável**: Cliente / Atendimento.
* **Procedimento**: Após isso, o cliente deverá enviar o espelho para o atendimento geral poder aprovar.

</DocAccordion>

<DocAccordion title="3.1.3 [Comunicar aprovação]" stepNumber="3.1.3" id="gar-pj-rev-3-1-3">

* **Responsável**: Atendimento Geral.
* **Procedimento**: O atendimento deverá comunicar ao cliente caso o espelho tenha sido aprovado.

</DocAccordion>

<DocAccordion title="3.1.4 [Cliente Transmite NFe]" stepNumber="3.1.4" id="gar-pj-rev-3-1-4">

* **Responsável**: Cliente.
* **Procedimento**: A partir da aprovação, o cliente deverá **transmitir** a NFe de devolução (enviar para a receita).

</DocAccordion>

<DocAccordion title="3.1.5 [Cliente trazer peça e NFe]" stepNumber="3.1.5" id="gar-pj-rev-3-1-5">

* **Responsável**: Cliente / Atendimento.
* **Procedimento**: O cliente deverá trazer a peça junto com a NFe para a loja física.

</DocAccordion>
